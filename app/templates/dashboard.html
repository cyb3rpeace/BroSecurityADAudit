С чего начать

Каталог читает Linux по LDAP или LDAPS. PingCastle и SharpHound ставятся на любой Windows-компьютер в домене: Windows Server 2019 или рабочая станция офицера безопасности. На контроллер их ставить не обязательно.

Настрой LDAP/LDAPS, установи BloodHound и PingCastle и приступай к сканированию!

Каталог: LDAPS 636 и простой LDAP 389
  1. В «Настройках» укажите DNS-имя контроллера и служебную учетную запись этого же домена. Формат DOMAIN\user или user@domain. Права администратора домена не нужны, достаточно чтения.
  2. Выберите «Каталог: LDAPS, порт 636», если на контроллере включен сертификат. Для лаборатории или внутреннего ЦС проверка сертификата по умолчанию не блокирует соединение.
  3. Если LDAPS еще не включен, выберите «Каталог: LDAP, порт 389». Это обычный LDAP без шифрования. Откройте с сервера аудита до контроллера только TCP 389 и не используйте его через недоверенные сети.
  4. Сохраните карточку. Модули «Гигиена», «Доверия и SID» и типы шифрования Kerberos пойдут этим каналом, без программы на Windows.
Как скачать и установить PingCastle
  1. На Windows-хосте откройте выпуски Netwrix PingCastle: https://github.com/netwrix/pingcastle/releases. Возьмите последний zip с PingCastle.exe.
  2. Распакуйте в C:\Tools\PingCastle. Рядом окажется PingCastle.exe. Антивирус может спросить подтверждение: это сканер зрелости, не средство атаки.
  3. Хост должен быть в том же домене или уметь достучаться до контроллера по LDAP. Запуск от имени учетной записи с правом чтения каталога.
  4. Проверка вручную: PingCastle.exe --healthcheck --server ИМЯ-КОНТРОЛЛЕРА. Рядом появится XML. Пароль в командную строку не кладите.
Как скачать и установить SharpHound
  1. Откройте выпуски SpecterOps SharpHound: https://github.com/SpecterOps/SharpHound/releases. Скачайте SharpHound.exe той же ветки, что понимает BloodHound CE.
  2. Распакуйте в C:\Tools\SharpHound. Это сборщик графа. Он не выгружает хеши и билеты.
  3. BloodHound CE уже работает на сервере аудита во внутренней сети Docker. Наружу его публиковать не нужно. Сборщик только передает zip на сервер аудита, а сервер сам кладет архив в CE.
  4. Запускайте SharpHound в сессии доменной учетной записи чтения. Отдельный пароль в скрипт не записывается.
Как связать программы с сервером аудита

Два рабочих способа. Выберите тот, до которого сервер аудита реально достучится.

Способ А. Сервер сам заходит на Windows. В настройках заполните «Windows-хост» — это Server 2019 или компьютер офицера, не контроллер. Транспорт «WinRM» и порт 5986, открытый только с адреса сервера аудита. Учетная запись та же, что для каталога, плюс право удаленного PowerShell на этом хосте. Галочки PingCastle и BloodHound запустят уже установленные exe. Для реестра SMB, LLMNR и подписи LDAP WinRM нужен еще и на контроллере: эти параметры живут там.

Способ Б. Сборщик на самом Windows. Если до компьютера офицера сервер не достучится, в настройках оставьте «только сборщик» и нажмите «Собрать скрипт сборщика». Скопируйте его на Windows, поправьте пути, если exe лежат не в C:\Tools, и запустите. Скрипт вызовет PingCastle и SharpHound и отправит XML и zip на этот сайт. Токен внутри скрипта одноразовый для компании, пароля домена в нем нет.

Какая галочка что запускает
  • Гигиена, доверия, часть харденинга — LDAP или LDAPS с Linux.
  • Опасные протоколы — по LDAP типы шифрования DES и RC4; по WinRM на контроллере SMBv1, подпись SMB, LLMNR, NetBIOS, WPAD, WDigest, NTLMv1, подпись и привязка канала LDAP, анонимный сеанс, PowerShell 2.0, TLS 1.0.
  • PingCastle и SharpHound — Windows-хост из поля выше или сборщик.
  • Время, GPO, AD CS, полный харденинг — WinRM на контроллер. Значение cpassword не расшифровывается, билеты не запрашиваются.
Почта и Telegram

В «Настройках» суперадминистратор указывает SMTP организации и бота Telegram. Пароль и токен сохраняются на сервере и обратно в браузер не отдаются. После сканирования уходят письмо и сообщение: индекс, статус и список критических и высоких находок, к письму прикладывается PDF. Адрес получателя и отдельный chat id задаются в карточке компании. Кнопки «Проверить» отправляют короткое тестовое сообщение, не запуская сканирование.

Экраны, отчеты и MITRE ATT&CK
  • Обзор. Карточки, тренд, кольцо и строка тактик MITRE. Клик по тактике оставляет только связанные находки.
  • Инциденты. Фильтр уровня, статуса, категории и тактики MITRE. В карточке находки: номер техники, на что она влияет и как ее закрыть.
  • Отчеты. PDF и Excel содержат график, проблему, влияние, способ закрытия и номер MITRE. Это карта защиты, не инструкция атаки.
  • Разделы документации сворачиваются. «Развернуть все» и «Свернуть все» действуют сразу. Обновление страницы открывает обзор заново, язык и тема остаются в браузере.

Что система ищет

Строка — одна проверка: что найдено и что закрыть. PingCastle разобран по всем правилам текущего выпуска. BloodHound — как читать граф. Платформа сама домен не меняет.

Start here

The directory is read from Linux over LDAP or LDAPS. PingCastle and SharpHound run on any domain-joined Windows host: Server 2019 or the security officer workstation. They do not have to be installed on a domain controller.

LDAP 389 and LDAPS 636

Pick LDAPS 636 when the controller has a certificate. Pick plain LDAP 389 when LDAPS is not ready, and keep that port only on a trusted network. The same read account is enough. Use DOMAIN\user or user@domain.

Install and connect the tools

Download PingCastle from the Netwrix GitHub releases and SharpHound from the SpecterOps GitHub releases. Unzip them to C:\Tools\PingCastle and C:\Tools\SharpHound. Either point WinRM at that Windows host, or build the collector script in Settings and run it there. The script uploads the XML and the zip. It does not contain the domain password.

Reports and MITRE

PDF and Excel state the problem, the impact, how to close it, and the MITRE ATT&CK technique id. The overview has a tactic filter. Sections on this page expand and collapse.

Сканирование

Эти модули сервер запускает сам: каталог по LDAP и проверки Windows по WinRM. PingCastle и SharpHound загружаются в своих пунктах меню.

PingCastle

Программа запускается в обычном доменном входе на Windows. Сервер разбирает XML и кладет правила в общую статистику. Пароль в файл не входит.

Как снять срез

  1. Войдите на Windows-хост доменной учетной записью чтения. Не через удаленный WinRM.
  2. Запустите уже установленный PingCastle. Контроллер указывается ключом --server.
  3. Загрузите появившийся XML справа.
C:\Tools\PingCastle\PingCastle.exe --healthcheck --server ИМЯ-КОНТРОЛЛЕРА

Загрузка XML

Отчет PingCastle
Файл ad_*.xml, не больше 20 МБ

SharpHound

Сборщик запускается в том же доменном входе. В платформу попадает zip. Хеши и билеты не запрашиваются.

Как собрать граф

  1. На Windows-хосте откройте обычную доменную сессию, не WinRM.
  2. Запустите SharpHound методами DCOnly, Session, LocalAdmin и CA.
  3. Загрузите zip справа. Сервер передаст его в BloodHound CE и обновит пути атак.
C:\Tools\SharpHound\SharpHound.exe -c DCOnly,Session,LocalAdmin,CA --zipfilename brosec --nosavecache

Настройки

Подключение к каталогу, тенанты и администраторы.

1. Каталог

Служебная учетная запись домена. Linux открывает LDAPS и сам читает пользователей, группы, доверия и схему. Скрипт на Windows для этого не нужен.

2. Программы

PingCastle.exe и SharpHound.exe ставятся на любой Windows: Server 2019 или компьютер офицера. Контроллер для этого не нужен. Либо WinRM на этот хост, либо сборщик, который сам отправит результат.

3. Оба канала

Одна учетная запись чтения. Каталог идет по LDAP или LDAPS. PingCastle и SharpHound — с отдельного Windows-хоста или сборщиком. Реестр, время и SYSVOL — по WinRM на контроллер.

1. Directory

A domain service account. Linux opens LDAPS and reads users, groups, trusts, and schema. No Windows script is required for that.

2. Programs

Install PingCastle.exe and SharpHound.exe on any Windows host: Server 2019 or the officer workstation. The domain controller is not required. Use WinRM to that host, or the collector script.

3. Both channels

One read account. The directory uses LDAP or LDAPS. PingCastle and SharpHound run on a separate Windows host or via the collector. Registry, time, and SYSVOL use WinRM to the controller.

Корпоративная почта

Отчеты и алерты уходят через почтовый сервер организации. Пароль в карточку после сохранения не возвращается.

Telegram

Один бот на установку. Chat id компании, если заполнен, перекрывает общий чат. Токен после сохранения не показывается.

ИИ-ассистент

Любая модель с адресом в формате OpenAI, путь заканчивается на /v1. Ключ после сохранения не показывается. Пустое поле ключа оставляет уже сохраненный ключ или ключ сервера.

Подключение к Active Directory

LDAP 389 или LDAPS 636 читает каталог с Linux. PingCastle и SharpHound запускаются на любом Windows-хосте или сборщиком. Реестр читается по WinRM с контроллера.
