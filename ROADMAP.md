# 🗺️ Дорожная карта

Сроков здесь нет. Это направление продукта.

## 🔎 Шире проверки каталога

Добавить правила, которых еще нет: делегирование, незащищенные группы, устаревшие протоколы на остальных контроллерах и более точная картина привилегий.

## 🛡️ OpenVAS

Отдельный контур: версия системы и открытые службы сверяются с базой уязвимостей, а не только с черным списком программ.

## ⚡ Velociraptor

Запросы для поиска аномалий и хантинга. Удаленный запуск PingCastle и SharpHound с отдельного Windows-хоста до этой интеграции не используется: отчеты загружаются вручную.

## 👻 Быстрый Shadow IT

Сейчас обход установленных программ идет по WinRM и занимает долго. Velociraptor должен собирать программы быстрее, в том числе с хостов, где WinRM закрыт.

## 🕸️ Граф BloodHound CE

Загрузка архива SharpHound уже есть. Прием графа в BloodHound CE еще нужно довести: пока API входа отвечает ошибкой, пути атак из графа не строятся.
